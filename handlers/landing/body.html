Use unsafe signature for quick testing. In production, replace unsafe with a signed path according to your signature key.

Resize Option

Generated segment format:

rs:{type}:{width}:{height}:{enlarge}
  • type: fit, fill, crop, force, auto
  • width, height: positive integers
  • enlarge: 1 to allow upscaling, 0 to disable

Output Format

Append an output extension to force final encoding:

.../plain/{source}@webp
  • Common choices: jpg, png, webp, avif
  • Leave blank to keep source type when possible

Path Template Reference

/{signature}/{processing_options}/plain/{source_url}@{ext}
  • signature: unsafe for testing, or a real signed value
  • processing_options: slash-separated option segments
  • source_url: full upstream image URL
  • ext: optional output extension
